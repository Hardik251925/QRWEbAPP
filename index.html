How it works

iPhone / iPad

"View in AR" tap karo → Apple AR Quick Look launch hoga. Ye native ARKit use karta hai. Floor/table automatically detect hoga, model wahi place hoga. Pinch to scale, drag to move.

Android

"View in AR" tap karo → Google Scene Viewer launch hoga. Ye native ARCore use karta hai. Surface detect hoga, model place hoga. No Chrome flags needed, no WebXR required.

Key difference from WebXR

WebXR = AR browser ke andar chalta hai (Chrome flags, limited iOS support).
Scene Viewer + Quick Look = Native apps launch hote hain — best quality plane detection, koi flag enable nahi karna, iOS + Android dono mein kaam karta hai.

The key code

// WebXR REMOVED from ar-modes // Default: "webxr scene-viewer quick-look" // Ours: "scene-viewer quick-look" <model-viewer src="model.glb" ios-src="model.usdz" ar ar-modes="scene-viewer quick-look" ar-scale="auto" camera-controls ></model-viewer> // That's it! No WebXR. // Android → Scene Viewer (ARCore) // iOS → Quick Look (ARKit)

Apna model use karna hai?

Step 1: Blender mein model banao ya download karo
Step 2: Export as .glb (File → Export → glTF Binary)
Step 3: Export as .usdz (File → Export → USD) — iOS ke liye
Step 4: src="model.glb" aur ios-src="model.usdz" mein path dalo
Step 5: HTTPS pe host karo (GitHub Pages / Netlify)
Done! Phone pe kholo → "View in AR" → plane detect → object place!
